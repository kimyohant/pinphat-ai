# Pinphat AI

ต้นแบบแพลตฟอร์มปัญญาประดิษฐ์เพื่อการอนุรักษ์ ถ่ายทอด และส่งเสริมการเรียนรู้ดนตรีพิณพาทย์ล้านช้าง สำหรับสถานศึกษาในกลุ่มจังหวัดอีสานตอนเหนือ

แบบระบบฉบับเต็ม: https://claude.ai/artifact/4jSiypTwPX5zQ38gAj7v1i

> ข้อมูลทั้งหมดในเวอร์ชันนี้ (ครูภูมิปัญญา เพลง ทาง บทสัมภาษณ์ และเสียง) เป็นข้อมูลสมมติเพื่อการสาธิต เสียงสังเคราะห์ด้วยโปรแกรม

## เริ่มใช้งาน

ต้องใช้ Node.js 24 ขึ้นไป (ใช้ฐานข้อมูล SQLite ที่มากับ Node)

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 แล้วกด "เลือกบทบาทเพื่อทดลองใช้" ระบบสร้างฐานข้อมูลและข้อมูลตัวอย่างใน `data/` ให้อัตโนมัติเมื่อเปิดครั้งแรก

ล้างข้อมูลทั้งหมดและเริ่มใหม่: หยุดเซิร์ฟเวอร์ แล้ว `npm run reset`

### เปิดใช้ LLM สำหรับครูผู้ช่วย AI

คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `ANTHROPIC_API_KEY` ระบบใช้ `claude-opus-5-5` เป็นค่าเริ่มต้น (เปลี่ยนได้ด้วย `PINPHAT_MODEL`) ถ้าไม่ตั้งค่า ครูผู้ช่วย AI จะตอบด้วยข้อความที่ค้นคืนจากคลังโดยตรงพร้อมเลขอ้างอิง

## บทบาทและสิ่งที่ทำได้

| บทบาท | หน้า | ทำอะไรได้ |
|---|---|---|
| นักเรียน | ฝึกเล่น, ครูผู้ช่วย AI | ฝึกกับโค้ช AI (ระนาดบนจอหรือเครื่องจริงผ่านไมค์) ระบบให้คะแนนรายห้องและบันทึกผลให้ครู |
| ครูดนตรี | ห้องเรียน | ดูความแม่นของนักเรียน ห้องที่ทั้งชั้นพลาดบ่อย มอบหมายงาน สร้างบทเรียนจากการบรรเลงที่รับรองแล้ว |
| ผู้เก็บข้อมูลภาคสนาม | Field Studio | สร้างรอบบันทึก บันทึกความยินยอมและป้าย TK อัปโหลดเสียง (เก็บ SHA-256) ให้ AI ถอดโน้ตและวัดระบบเสียง |
| ผู้เชี่ยวชาญตรวจรับรอง | ตรวจรับรอง | ตรวจผลจาก AI แก้โน้ตรายห้อง รับรองแล้วนำเข้าดัชนีความรู้ ดูคำตอบ AI ที่ผู้ใช้แจ้งว่าผิด |
| ผู้ประสานงานชุมชน | ความยินยอม | เปลี่ยนระดับสิทธิ์ ถอนความยินยอม (ความรู้หายจากดัชนี AI ทันที) ดูบันทึกการเปลี่ยนแปลง |

## สถาปัตยกรรม

- **Next.js 16 (App Router)** หน้าเว็บและ API ในโปรเจกต์เดียว
- **SQLite (`node:sqlite`)** ไฟล์เดียวที่ `data/pinphat.db` ไฟล์เสียงต้นฉบับอยู่ที่ `data/media/`
- **สิทธิ์ 5 ระดับ** (`lib/access.ts`) ติดไปกับความยินยอม → ส่วนย่อย → ชิ้นความรู้ในดัชนี AI → ไฟล์เสียง ตรวจทุกคำขอ
- **คลังความรู้ + RAG** (`lib/kb.ts`) ความรู้อยู่ในฐานข้อมูล ไม่ได้ฝังในโมเดล ค้นคืนด้วย character trigram (ภาษาไทยไม่เว้นวรรคระหว่างคำ) กรองสิทธิ์ก่อนค้น และกรองตามบุคคลเมื่อคำถามเอ่ยชื่อครู
- **LLM Gateway** (`lib/llm.ts`) ส่งเฉพาะชิ้นความรู้ที่ผ่านการกรองสิทธิ์ บังคับให้ตอบจากแหล่งและอ้างอิง [n]
- **วิเคราะห์เสียง** (`lib/audio.ts`, `lib/pitch.ts`) ตรวจจุดเริ่มเสียง วัดระดับเสียงแบบ NSDF ประมาณเสียง ด ของวง จัดลงช่องจังหวะ (ลูกตกลงจังหวะฉับ) และวัดค่าเพี้ยนจากระบบ 7 เสียงเท่าเป็น cents
- **โค้ชฝึกซ้อม** (`components/PracticeCoach.tsx`) Web Audio ในเบราว์เซอร์ ไม่ส่งเสียงนักเรียนขึ้นเซิร์ฟเวอร์

## ข้อจำกัดของต้นแบบ

- เข้าสู่ระบบด้วยบัญชีทดลอง ยังไม่มีรหัสผ่านหรือ SSO
- วิเคราะห์อัตโนมัติได้เฉพาะไฟล์ WAV ที่บรรเลงเครื่องเดียว ยังไม่แยกเสียงในวง และยังไม่ถอดความเสียงพูด (ASR)
- ยังไม่ทำงานออฟไลน์แบบ PWA
- ตัวถอดโน้ตทดสอบกับเสียงสังเคราะห์เท่านั้น ต้องประเมินกับการบันทึกภาคสนามจริงก่อนรายงานค่าความแม่นยำในข้อเสนอโครงการ
