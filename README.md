# Pinphat AI

ต้นแบบแพลตฟอร์มปัญญาประดิษฐ์เพื่อการอนุรักษ์ ถ่ายทอด และส่งเสริมการเรียนรู้ดนตรีพิณพาทย์ล้านช้าง สำหรับสถานศึกษาในกลุ่มจังหวัดอีสานตอนเหนือ

แบบระบบฉบับเต็ม: https://claude.ai/artifact/4jSiypTwPX5zQ38gAj7v1i

> ข้อมูลทั้งหมดในเวอร์ชันนี้ (ครูภูมิปัญญา เพลง ทาง บทสัมภาษณ์ และเสียง) เป็นข้อมูลสมมติเพื่อการสาธิต เสียงสังเคราะห์ด้วยโปรแกรม

## เริ่มใช้งาน

ต้องใช้ Node.js 24 ขึ้นไป (ใช้ฐานข้อมูล SQLite ที่มากับ Node)

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 แล้วกด "เลือกบทบาทเพื่อทดลองใช้" ระบบสร้างฐานข้อมูลและข้อมูลตัวอย่างใน `data/` ให้อัตโนมัติเมื่อเปิดครั้งแรก

ล้างข้อมูลทั้งหมดและเริ่มใหม่: หยุดเซิร์ฟเวอร์ แล้ว `npm run reset`

### เชื่อมเซิร์ฟเวอร์ AI (Unsloth Studio)

คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `UNSLOTH_BASE_URL` และ `UNSLOTH_API_KEY` (ไฟล์นี้ไม่ถูก commit) ต้องรีสตาร์ต `npm run dev` หลังแก้ไฟล์

| งาน | โมเดลเริ่มต้น | endpoint |
|---|---|---|
| ครูผู้ช่วย AI, ช่วยเขียน prompt | `unsloth/Qwen3.8-27B-GGUF` (UD-Q5_K_M, context 32K) | `/v1/chat/completions` |
| รูปประกอบบทเรียน | `Qwen/Qwen-Image-2.1` | `/v1/images/generations` |
| วิดีโอสั้น | `unsloth/Wan2.2-TI2V-5B-GGUF` | `/v1/videos` |
| ถอดความบทสัมภาษณ์ | Whisper `large-v3-turbo` (ตั้งด้วย `UNSLOTH_STT_MODEL`) | `/v1/audio/transcriptions` |

เซิร์ฟเวอร์ถือโมเดลบน GPU ได้ทีละตัว แอปจึงสลับโมเดลให้ตามงาน (`lib/unsloth.ts`) และทำงานทีละชิ้นผ่านคิวเดียว
- ตัวถอดเสียงทำงานเป็น sidecar คู่กับโมเดลภาษา ไม่ต้องสลับโมเดลและไม่ต้องรอคิว GPU
- แอปจะไม่สลับโมเดลระหว่างที่เซิร์ฟเวอร์กำลังสร้างรูปหรือวิดีโอ (รวมงานที่สั่งจากหน้า Unsloth Studio โดยตรง) ช่วงนั้นครูผู้ช่วย AI จะตอบแบบค้นคืนจากคลังแทน
- เวลาโดยประมาณ: ตอบคำถาม 5–30 วินาที, รูป 20 วินาที–1 นาที, วิดีโอ 4 วินาทีที่ 1280×704 ราว 13 นาที (บวกเวลาสลับโมเดลราว 30–60 วินาที)

ถ้าต้องการใช้ Claude สำหรับครูผู้ช่วยแทน ตั้ง `PINPHAT_LLM_PROVIDER=claude` และ `ANTHROPIC_API_KEY` ถ้าไม่ตั้งค่าผู้ให้บริการใดเลย ครูผู้ช่วยจะตอบด้วยข้อความที่ค้นคืนจากคลังพร้อมเลขอ้างอิง

## บทบาทและสิ่งที่ทำได้

| บทบาท | หน้า | ทำอะไรได้ |
|---|---|---|
| นักเรียน | ฝึกเล่น, ครูผู้ช่วย AI | ฝึกกับโค้ช AI (ระนาดบนจอหรือเครื่องจริงผ่านไมค์) ระบบให้คะแนนรายห้องและบันทึกผลให้ครู |
| ครูดนตรี | ห้องเรียน, สตูดิโอสื่อ | ดูความแม่นของนักเรียน ห้องที่ทั้งชั้นพลาดบ่อย มอบหมายงาน สร้างบทเรียนจากการบรรเลงที่รับรองแล้ว สร้างรูปและวิดีโอประกอบบทเรียนด้วย AI |
| ผู้เก็บข้อมูลภาคสนาม | Field Studio | สร้างรอบบันทึก บันทึกความยินยอมและป้าย TK อัปโหลดเสียง (เก็บ SHA-256) ให้ AI ถอดโน้ต วัดระบบเสียง และถอดความบทสัมภาษณ์ (ไทย/อีสาน/ลาว) เป็นร่างให้ผู้เชี่ยวชาญตรวจ |
| ผู้เชี่ยวชาญตรวจรับรอง | ตรวจรับรอง | ตรวจผลจาก AI แก้โน้ตรายห้อง รับรองแล้วนำเข้าดัชนีความรู้ ดูคำตอบ AI ที่ผู้ใช้แจ้งว่าผิด |
| ผู้ประสานงานชุมชน | ความยินยอม | เปลี่ยนระดับสิทธิ์ ถอนความยินยอม (ความรู้หายจากดัชนี AI ทันที) ดูบันทึกการเปลี่ยนแปลง |

## สถาปัตยกรรม

- **Next.js 16 (App Router)** หน้าเว็บและ API ในโปรเจกต์เดียว
- **SQLite (`node:sqlite`)** ไฟล์เดียวที่ `data/pinphat.db` ไฟล์เสียงต้นฉบับอยู่ที่ `data/media/`
- **สิทธิ์ 5 ระดับ** (`lib/access.ts`) ติดไปกับความยินยอม → ส่วนย่อย → ชิ้นความรู้ในดัชนี AI → ไฟล์เสียง ตรวจทุกคำขอ
- **คลังความรู้ + RAG** (`lib/kb.ts`) ความรู้อยู่ในฐานข้อมูล ไม่ได้ฝังในโมเดล ค้นคืนด้วย character trigram (ภาษาไทยไม่เว้นวรรคระหว่างคำ) กรองสิทธิ์ก่อนค้น และกรองตามบุคคลเมื่อคำถามเอ่ยชื่อครู
- **LLM Gateway** (`lib/llm.ts`) ส่งเฉพาะชิ้นความรู้ที่ผ่านการกรองสิทธิ์ บังคับให้ตอบจากแหล่งและอ้างอิง [n]
- **วิเคราะห์เสียง** (`lib/audio.ts`, `lib/pitch.ts`) ตรวจจุดเริ่มเสียง วัดระดับเสียงแบบ NSDF ประมาณเสียง ด ของวง จัดลงช่องจังหวะ (ลูกตกลงจังหวะฉับ) และวัดค่าเพี้ยนจากระบบ 7 เสียงเท่าเป็น cents
- **สตูดิโอสื่อ** (`lib/studio.ts`) งานสร้างรูป/วิดีโอทำเบื้องหลังบนเซิร์ฟเวอร์ ไฟล์อยู่ที่ `data/studio/` ติดป้าย "สร้างโดย AI" และไม่เข้าคลังความรู้
- **โค้ชฝึกซ้อม** (`components/PracticeCoach.tsx`) Web Audio ในเบราว์เซอร์ ไม่ส่งเสียงนักเรียนขึ้นเซิร์ฟเวอร์

## ข้อจำกัดของต้นแบบ

- เข้าสู่ระบบด้วยบัญชีทดลอง ยังไม่มีรหัสผ่านหรือ SSO
- ถอดโน้ตอัตโนมัติได้เฉพาะไฟล์ WAV ที่บรรเลงเครื่องเดียว ยังไม่แยกเสียงในวง
- ถอดความสัมภาษณ์ทดสอบแล้วเฉพาะกับเสียงภาษาอังกฤษ ความแม่นกับภาษาอีสานต้องวัดจากไฟล์สัมภาษณ์จริง (Whisper ไม่ได้ฝึกภาษาอีสานโดยตรง)
- ยังไม่ทำงานออฟไลน์แบบ PWA
- รูปและวิดีโอจาก AI มักวาดเครื่องดนตรีผิดจากของจริง (เช่น ระนาดเอกออกมาคล้าย marimba) ใช้เป็นภาพประกอบบรรยากาศเท่านั้น
- เซิร์ฟเวอร์ AI เชื่อมต่อผ่าน HTTP ธรรมดา คีย์ API และข้อมูลคลังความรู้ที่ส่งไปจึงไม่ได้เข้ารหัสระหว่างทาง ควรใช้ HTTPS หรือ VPN ก่อนใช้กับข้อมูลจริง
- ตัวถอดโน้ตทดสอบกับเสียงสังเคราะห์เท่านั้น ต้องประเมินกับการบันทึกภาคสนามจริงก่อนรายงานค่าความแม่นยำในข้อเสนอโครงการ
